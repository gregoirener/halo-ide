## Why Halo?

Halo is designed to help developers stay in flow:

- Clean, distraction-free interface
- Fast local development workflows
- Built for macOS users
- A focused environment for building and iterating quickly

## Features

- Interactive coding experience

- Simple, focused environment for experimentation and product development
